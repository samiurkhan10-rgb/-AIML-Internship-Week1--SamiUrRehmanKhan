## 📌 Project Overview

This project performs a comprehensive Exploratory Data Analysis (EDA) on a dataset of 1000 students to understand the factors influencing academic performance in:

- 📊 Math
- 📖 Reading
- ✍️ Writing

The analysis follows a structured pipeline including data inspection, statistical analysis, visualization, feature engineering, and NumPy-based computations.

---

## 🎯 Objectives

- Analyze student performance patterns
- Identify key influencing factors
- Explore relationships between subjects
- Evaluate impact of demographics and test preparation

---

## 🗂 Dataset

- Source: Kaggle (Students Performance Dataset)
- Records: 1000 students
- Features:
  - Gender
  - Race/Ethnicity
  - Parental Level of Education
  - Lunch Type
  - Test Preparation Course
  - Math, Reading, Writing Scores

## 🔍 Key Analysis Performed

### 📊 1. Data Exploration
- Dataset structure and quality analysis
- Missing values and duplicates check

### 📈 2. Statistical Analysis
- Mean, median, standard deviation
- Variance and distribution analysis

### 📉 3. Visualization
- Histograms
- Boxplots
- Pairplots
- Heatmaps
- Dashboard (6-chart layout)

### 🧠 4. Feature Engineering
- Total Score
- Average Score
- Performance Grade (A–F)
- High Achiever Indicator
- Lowest Subject

### 🧮 5. NumPy Analysis
- Manual mean, variance, std
- Z-score outlier detection
- Percentile analysis
- Top performers identification

---

## 📊 Key Insights

- 📌 Reading & Writing are highly correlated (**0.95**)
- 📌 Math is the most challenging subject (highest variability)
- 📌 Test preparation improves performance by up to **15%**
- 📌 Students with higher parental education perform better
- 📌 Only **39.1%** of students scored above 70 in math
- 📌 Socioeconomic factors (lunch type) impact performance
